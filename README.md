One pickup line, written as if a vending machine were flirting with a passing human.

## Entry

> My coils only drop the good stuff for people who press the right buttons — and you just pressed all of mine.

## How it works

`main.ts` (Node stdlib only) copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`, resolving the entry file relative to the script's own directory.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
